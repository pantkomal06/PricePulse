
# PricePulse — Price Tracking and Trend Analysis

## Overview
PricePulse is a full-stack price tracking project designed
to monitor product prices, analyze historical trends, and
provide price alerts and AI-assisted buying recommendations.

## Project Components
- Product price tracking and data collection
- Historical price storage
- Price trend visualization
- Threshold-based price alerts
- AI-assisted buy/wait recommendations

## Technology Stack
React, Node.js, Express.js, MongoDB, Gemini API
